# Aavin Sales Data Analysis Using Python

## About the Project
This project is about exploring and understanding Aavin sales data using Python. I worked with the dataset to see how sales vary across different products, districts, outlet types, and payment methods.

The main aim of this project was to practise data cleaning, explore the dataset, and use visualizations to understand sales patterns.

## Tools & Libraries Used

- Python
- Pandas
- Numpy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Overview

The dataset initially contained 8,080 records and 10 columns.

It includes information such as:
- Order ID and order date
- District and outlet type
- Product name and category
- Unit price and quantity sold
- Revenue and payment mode

## What I Did

I started by exploring the dataset to understand its structure, columns, and data types.

After that, I worked on cleaning the data. This included checking for duplicate records, handling missing values, converting the order date into a proper date format, and making text values consistent.

Once the data was cleaned, I used Pandas to group and analyse the sales information. I also created visualizations using Matplotlib and Seaborn to make the results easier to understand.

## Analysis Performed

Some of the areas I explored in this project include:

- Monthly revenue trends to understand how revenue changes over time.
- Average revenue across different outlet types.
- Revenue generated by different product categories.
- Revenue comparison across districts.
- Payment mode distribution to understand how customers make payments.

## What I Learned

Working on this project gave me practical experience in handling a dataset from the initial exploration stage to visualization.

I got more practice with Pandas for data cleaning and grouping, and Matplotlib and Seaborn for creating charts. It also helped me understand how data analysis can be used to identify patterns and make information easier to interpret.

## Conclusion

This project was a good learning experience and helped me improve my practical understanding of Python-based data analysis. I look forward to working on more projects and exploring different datasets.
